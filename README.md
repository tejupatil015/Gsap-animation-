
# ✨ Luxury Residences — Cinematic Real Estate Website

A modern, visually immersive luxury real estate website built with React, GSAP, and modern frontend technologies.

The project focuses on smooth scrolling experiences, cinematic image reveals, interactive galleries, and elegant UI animations to create a premium digital experience.

## 🌐 Live Demo

[View Live Website](YOUR_DEPLOYED_WEBSITE_URL)

## 📸 Features

- **Cinematic Hero Section** — Animated images, text reveals, and mouse-based parallax effects.
- **GSAP Scroll Animations** — Smooth, sequential animations triggered when sections enter the viewport.
- **Expandable Image Gallery** — Interactive cards with hover-based expansion.
- **Dynamic Card Details** — Individual detail pages with animated transitions.
- **Residences Slideshow** — Automatic image transitions with smooth fade effects.
- **Collection Showcase** — Interactive property collections with navigation controls.
- **Responsive UI** — Designed for a modern browsing experience.
- **Smooth Navigation** — React Router-based page navigation.

## 🎬 Animation Experience

This project uses GSAP to create a more engaging browsing experience.

### ScrollTrigger Animations
- Animations begin when their respective sections enter the viewport.
- Images reveal with scale and clip-path transitions.
- Headings and descriptions appear sequentially.
- Entrance animations play once.

### Interactive Animations
- Hover-based expandable cards.
- Mouse movement parallax effects.
- Automatic residence image slideshow.
- Smooth collection image transitions.
